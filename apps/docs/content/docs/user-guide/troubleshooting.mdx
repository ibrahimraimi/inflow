If you're having trouble with Inflow, check the solutions below.

## Missing Data / No Visitors Recorded

If your site is live but you don't see any data in Inflow:

1. **Check the Script Installation**: View your website's source code (`Ctrl+U` or `Cmd+Option+U`) and search for `analytics.js`. Ensure it's inside the `<head>` tag.
2. **Verify Website ID**: Double-check that the `data-website-id` in your script matches the one provided in the Inflow dashboard.
3. **Domain Verification**: Ensure the `data-domain` attribute matches the domain you registered (case-sensitive, e.g., `example.com` vs `www.example.com`).
4. **Localhost Testing**: Traffic from `localhost` is ignored by default. Enable "Localhost Tracking" in Website Settings if you are testing locally.
5. **Ad-blockers**: Disable ad-blockers like uBlock Origin or Adblock Plus to see if they are interfering with the tracking script.

## Dashboard Loading Issues

- **Clear Browser Cache**: Sometimes old assets can cause UI glitches. Try a hard refresh (`Ctrl+F5` or `Cmd+Shift+R`).
- **Check Storage**: If you are self-hosting, ensure your database has enough storage space left.

## Invitation Not Received

- **Check Spam Folder**: Emails are sent via Resend. Ask the user to check their spam or junk folder.
- **Resend Invite**: You can delete and re-send the invitation from the **Settings > Team** page.

## "Unauthorized" Error

- **Login Session**: Your session might have expired. Try logging out and logging back in.
- **Permissions**: Ensure you are an Admin or Owner of the organization you are trying to modify.
