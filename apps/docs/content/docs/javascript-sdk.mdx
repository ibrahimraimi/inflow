The Inflow JavaScript SDK is the easiest way to track traffic and custom events on your website. It is lightweight, privacy-focused, and supports vanilla JavaScript as well as modern frameworks like React, Vue, and Svelte.

## Installation

### Script Tag (CDN)
The simplest way to get started is by adding our script tag to the `<head>` of your website. Replace `YOUR_API_KEY` with an API key from your **Settings > Keys** page, and `YOUR_WEBSITE_ID` with the ID found in your website settings.

```html
<script defer src="/cdn/inflow.js"></script>
<script>
  window.addEventListener('load', () => {
    inflow.init({ 
      apiKey: 'YOUR_API_KEY',
      websiteId: 'YOUR_WEBSITE_ID',
      endpoint: '/api/track' // Default endpoint
    });
  });
</script>
```

### NPM / Package Manager
For modern web applications, you can install the SDK as a dependency:

```bash
bun add @inflow/sdk
# or
npm install @inflow/sdk
```

## Core Methods

### `inflow.init(config)`
Initializes the SDK. This must be called before any tracking can occur.

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `apiKey` | `string` | Yes | Your account API key (prefixed with `inflow_`). |
| `websiteId` | `string` | Yes | The unique ID of the website you are tracking. |
| `endpoint` | `string` | No | The tracking API URL. Defaults to `/api/track`. |
| `debug` | `boolean` | No | Enable detailed logging. |
| `autoTrack` | `boolean` | No | Automatically track page views and SPA routes. Defaults to `true`. |

### `inflow.track(eventName, [properties])`
Tracks a custom event with optional properties.

```javascript
inflow.track('button_click', {
  button_id: 'signup_hero',
  color: 'blue'
});
```

### `inflow.identify(userId, [traits])`
Identifies a user and associates traits with them.

```javascript
inflow.identify('user_123', {
  plan: 'premium',
  email: 'user@example.com'
});
```

## Framework Support

### React
```tsx
import { InflowProvider } from '@inflow/sdk/react';

function App() {
  return (
    <InflowProvider config={{ 
      apiKey: 'inflow_...', 
      websiteId: 'YOUR_WEBSITE_ID' 
    }}>
      <YourApp />
    </InflowProvider>
  );
}
```

### Vue
```javascript
import { createInflow } from '@inflow/sdk/vue';

const app = createApp(App);
app.use(createInflow({ 
  apiKey: 'inflow_...', 
  websiteId: 'YOUR_WEBSITE_ID' 
}));
```

### Svelte
```javascript
import { initInflow } from '@inflow/sdk/svelte';

initInflow({ 
  apiKey: 'inflow_...', 
  websiteId: 'YOUR_WEBSITE_ID' 
});
```

## Automatic Tracking
By default, Inflow automatically captures:
- **Page Views**: On initial load and every time the URL changes (for SPAs).
- **Referrer**: Where the user came from.
- **Duration**: How long they stay on a page (calculated on backend via sessions).
