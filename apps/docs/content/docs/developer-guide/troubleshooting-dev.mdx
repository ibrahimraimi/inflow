This guide covers common issues core developers might encounter.

## Environment Issues

### "Database Connection Failed"
- Ensure your Docker containers are running: `docker ps`.
- Check if your `DATABASE_URL` in `.env.local` points to `localhost:5432` (or the port defined in `docker-compose.yml`).
- If using SSL, ensure your connection string includes `?sslmode=require`.

### "Too Many Requests (429)"
- Your local IP might be getting rate-limited by Upstash Redis.
- Temporarily increase the limit in `src/app/api/track/route.ts` or disable rate-limiting in development.

## Auth Issues

### "Redirect Loop during Login"
- Check if `BETTER_AUTH_URL` is correctly set.
- Clear browser cookies and storage for `localhost`.

### "Invitation Link Not Working"
- Port 3000 must be accessible.
- Ensure `NEXT_PUBLIC_APP_URL` matches the URL you are using to access the app.

## Debugging Techniques

- **Server-side logs**: Use `console.log` and check the terminal where `bun run dev` is running.
- **Edge logs**: For `/api/track`, use `console.log` and view logs in the Vercel dashboard (or browser console if testing with a local setup that supports Edge logging).
- **Network Tab**: Use the browser developer tools to inspect the payload sent to `/api/track` and the response from `/analytics`.
