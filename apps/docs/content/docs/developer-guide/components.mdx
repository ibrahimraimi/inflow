Inflow uses a modular component architecture based on **Radix UI** primitives and **Vanilla CSS**.

## Component Categories

### 1. Dashboard Components (`src/components/dashboard`)
These components are specifically for analytics visualization.

- **`AnalyticsDashboard`**: The main container that fetches data and orchestrates sub-reports.
- **`Charts`**: Wrapper around Recharts for visual traffic representation.
- **`ReportTable`**: A generic table component for Pages, Sources, and Locations.
- **`RangeSelector`**: Handles date range picking and URL synchronization.

### 2. General UI Components (`src/components/ui`)
Low-level building blocks (mostly following Shadcn patterns).

- **`Button`, `Input`, `Checkbox`**: Form controls.
- **`Dialog` & `Modal`**: For popups like "Add Website".
- **`DropdownMenu`**: For profile and navigation menus.

### 3. Site Components (`src/components/site`)
Used on the marketing pages and documentation layout.

- **`Header` & `Footer`**: Global navigation.
- **`UserNav`**: Authentication state management in the header.

## Chart Usage Example

When adding new charts, ensure they are wrapped in a client-side only component to avoid SSR issues:

```tsx
import { LineChart, Line, XAxis, YAxis, Tooltip } from 'recharts';

export function TrafficChart({ data }) {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <LineChart data={data}>
        <Line type="monotone" dataKey="views" stroke="#10b981" />
        {/* ... */}
      </LineChart>
    </ResponsiveContainer>
  );
}
```

## Styling Guidelines

- **Vanilla CSS**: We prefer standard CSS for custom elements to maintain flexibility.
- **Tailwind**: Used for layout utilities (spacing, Flexbox, Grid).
- **Z-Index**: Keep z-index levels documented and consistent (e.g., Modals at 50, Tooltips at 100).
