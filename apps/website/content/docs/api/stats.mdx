---
title: Stats API
description: Programmatically retrieve your analytics data.
---

The Stats API allows you to fetch aggregated metrics and reports for your websites. This is the same API that powers the Inflow dashboard.

## Endpoint

```http
GET https://your-inflow-instance.com/api/website/{websiteId}/analytics
```

## Authentication

Currently, this API requires an active session cookie. In a future update, we will support **API Keys** for backend-to-backend integration.

## Query Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `range` | string | `last_7_days` | Time range: `last_24_hours`, `last_7_days`, `last_30_days`, `last_90_days`. |
| `from` | string | - | ISO timestamp for custom start date. |
| `to` | string | - | ISO timestamp for custom end date. |

## Example Request

```bash
curl "https://inflow.example.com/api/website/test-site-id/analytics?range=last_30_days" \
  -H "Cookie: better-auth.session-token=..."
```

## Example Response

```json
{
  "metrics": {
    "visitors": 1250,
    "visits": 1800,
    "views": 4500,
    "bounceRate": 42.1,
    "duration": 58
  },
  "reports": {
    "pages": [
      { "path": "/", "views": 2000, "percentage": 44.4 },
      { "path": "/pricing", "views": 800, "percentage": 17.7 }
    ],
    "sources": [...],
    "locations": [...]
  }
}
```

## Error Codes

- `401 Unauthorized`: No active session found.
- `404 Not Found`: Website ID does not exist or you don't have access to it.
- `500 Internal Error`: Database aggregation failure.
