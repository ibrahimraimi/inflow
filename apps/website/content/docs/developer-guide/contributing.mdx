First off, thank you for considering contributing to Inflow. It's people like you that make Inflow such a great tool for the community.

## How Can I Contribute?

### Reporting Bugs
- Use the [GitHub Issue Tracker](https://github.com/ibrahimraimi/inflow/issues).
- Describe the bug in detail, including steps to reproduce.
- Mention your environment (OS, Browser, Node version).

### Suggesting Enhancements
- Check the [Roadmap](https://github.com/ibrahimraimi/inflow/projects) to see if it's already planned.
- Open an issue with the "feature request" tag.

### Pull Requests
1. Fork the repo and create your branch from `develop`.
2. Ensure your code follows the [Coding Standards](/docs/developer-guide/coding-standards).
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure the test suite passes (`bun run test`).

## Community & Conduct

- **Code of Conduct**: Be respectful and professional.
- **Communication**: Join our [Discord](https://discord.gg/inflow) for real-time discussions.

## Roadmap Highlights

- Translation of dashboard UI into multiple languages.
