This page documents the internal APIs used by the Inflow tracking script and the dashboard.

## Tracking API

### `POST /api/track`
The primary ingestion endpoint. It is optimized for the Edge Runtime.

**Request Payload (`application/json`):**
```typescript
{
  type: "entry" | "exit";      // Type of event
  websiteId: string;           // Your Website ID
  domain: string;              // Registered domain
  url: string;                 // Current page URL
  clientId: string;            // Anonymous visitor ID (hash)
  referrer?: string;           // Referrer URL
  entryTime?: string;          // ISO timestamp
  exitTime?: string;           // ISO timestamp (for exit events)
  totalActiveTime?: number;    // Time spent on page in seconds
  // ... UTM parameters (utmSource, utmMedium, etc.)
}
```

**Response Codes:**
- `200 OK`: Data received successfully.
- `400 Bad Request`: Validation failed (Zod error).
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: Database connection issue.

## Analytics API

### `GET /api/website/[id]/analytics`
Fetches aggregated data for a specific website's dashboard.

**URL Parameters:**
- `id`: The internal Website ID.

**Query Parameters:**
- `range`: `last_24_hours`, `last_7_days` (default), `last_30_days`, `last_90_days`.
- `from`, `to`: ISO timestamps for custom date ranges.

**Response Body:**
```json
{
  "metrics": {
    "visitors": 120,
    "visits": 150,
    "views": 400,
    "bounceRate": 35.5,
    "duration": 45
  },
  "chart": [...],             // Data for the line chart
  "reports": {
    "pages": [...],
    "sources": [...],
    "locations": [...],
    "devices": [...]
  }
}
```

## Team & Management

### `POST /api/website`
Creates a new website for the active organization.

### `GET /api/accept-invitation/[id]`
Accepts an organization invitation.
